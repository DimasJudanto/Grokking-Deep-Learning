# Grokking-Deep-Learning
membahas dasar dasar deep learning secara bertahap, mulai dari pengenalan konsep hingga membangun jaringan saraf sederhana.
Chapter 1 memperkenalkan deep learning, manfaatnya, dan bagaimana teknologi ini digunakan untuk mempelajari pola dari data. 
Chapter 2 menjelaskan konsep fundamental tentang bagaimana mesin belajar melalui prediksi, kesalahan (error), dan penyesuaian bobot (weights). 
Chapter 3 membahas neural prediction menggunakan proses forward propagation, yaitu mengolah input melalui bobot untuk menghasilkan prediksi. 
Chapter 4 memperkenalkan neural learning melalui gradient descent, yaitu proses memperbaiki bobot berdasarkan kesalahan prediksi agar hasilnya semakin mendekati target. 
Chapter 5 mengembangkan konsep tersebut dengan mempelajari cara melatih banyak bobot sekaligus menggunakan beberapa input, perkalian elemen (element-wise multiplication), dan dot product untuk menghasilkan prediksi yang lebih kompleks. 
Terakhir, Chapter 6 menggabungkan konsep-konsep sebelumnya untuk membangun jaringan saraf dalam (deep neural network) sederhana yang memiliki lapisan tersembunyi (hidden layer) dan fungsi aktivasi ReLU, serta menggunakan backpropagation untuk memperbarui bobot berdasarkan kesalahan.
